# VINYL ROOM — React + Python + SQLite

Магазин виниловых пластинок с гостевым просмотром, кабинетом покупателя и
администратора. React-интерфейс сохраняет красно-оранжевое оформление сайта.

## Запуск

Нужны Python 3.10+ и Node.js 22.12+ (или 20.19+).
В терминале из папки VINYL_STORE:

```powershell
python -m pip install -r requirements.txt
cd frontend
npm ci
npm run build
cd ..
python run.py
```

Откройте http://localhost:8000. После первой сборки для обычного запуска
достаточно `python run.py`. После изменения React-кода повторите `npm run build`.
При занятом порте остановите прежний сервер через Ctrl+C и запустите новый.

Код регистрации администратора выводится в терминале при запуске.
Существующие аккаунты, заказы, обложки и SQLite сохранены в прежних местах.
Можно задать `ADMIN_INVITE_CODE` и `PORT` через переменные окружения.

## Разработка с обновлением без сборки

Терминал 1: `python run.py` (порт 8000).
Терминал 2: `cd frontend`, затем `npm run dev`.
Откройте адрес Vite из терминала (обычно http://127.0.0.1:5173).
Vite проксирует `/api` и `/covers` на Python. Сессии работают через HttpOnly cookie.
Не запускайте `npm run preview` отдельно от API для проверки магазина;
для готовой сборки используйте Python-сервер.

## Структура

```text
frontend/
  src/
    app/                маршруты, общий контекст каталога, аккаунта и корзины
    api/                HTTP-запросы и загрузка файлов
    components/         карточка альбома, обложка, модальное окно
    pages/              главная, каталог, альбом, личный кабинет
    features/
      auth/             вход и регистрация
      cart/             корзина и оформление заказа
      orders/           история и статусы заказов
      admin/            каталог и редактор с загрузкой обложек
    styles/             исходные стили сайта и стили новых страниц
  tests/                браузерный сценарий Playwright
  dist/                 готовая сборка (создаётся npm run build)
shop/                   Python API, SQLite, сессии, права, обработка изображений
static/covers/          запасные SVG и существующие фотографии
static/covers/albums/   фотографии с названиями album-name.jpg
static/covers/uploads/ обложки из админки: ID.jpg (автоматически)
data/shop.sqlite3      база магазина
tests/                 проверки API, обработки файлов и тестовый сервер
run.py                 запуск Python-сервера
```

Серверную папку `shop/` и данные не перемещали, чтобы сохранить прежние пути
и запуск. Старые `static/index.html`, `app.js`, `styles.css` удалены.
В `static/` остаются обложки. Если сборки `frontend/dist` нет, сервер
показывает сообщение «Сначала выполните сборку React» с командами
`cd frontend`, `npm ci`, `npm run build` (HTTP 503). После сборки
достаточно обновить страницу — перезапуск сервера не нужен.
**Для изменения актуального сайта редактируйте `frontend/src/`.**

## Страницы и роли

- `/` — главная с каталогом и блоком о магазине.
- `/catalog` — поиск, жанры и сортировка. Параметры сохраняются в URL.
- `/albums/ID` — отдельная страница альбома, наличие и похожие пластинки.
- `/favorites` — избранное покупателя.
- `/cart` — корзина и оформление заказа.
- `/account` — аккаунт, выход, ссылки на заказы и админку.
- `/orders` — свои заказы; администратор видит все и меняет статусы.
- `/admin` — добавление, редактирование, удаление товаров и обложки.

Гость просматривает каталог. Для корзины и избранного требуется аккаунт.
Регистрация администратора требует код приглашения. Сервер проверяет права,
цены и остатки, независимо от React. Отмена заказа возвращает остатки один раз.

## Загрузка обложек

Админка → «Изменить» или «Добавить пластинку» → «Загрузить обложку» →
«Сохранить пластинку». Предпросмотр появится до сохранения.

- JPG, PNG, WebP; максимум 5 МБ и 4096×4096 px.
- Рекомендуется квадрат 1000×1000 px.
- Имя исходного файла может быть любым.
- Сервер декодирует файл, применяет ориентацию EXIF и сохраняет JPEG до 1600 px.
- Файл хранится по ID альбома и не теряется при изменении названия.
- Существующие вручную добавленные изображения продолжают работать.
  Загруженная через админку обложка имеет приоритет.
- Если загрузка не удалась после сохранения товара, повторное сохранение
  обновит этот же товар, не создавая дубль.

Инструкция для ручного копирования:
[имена файлов](static/covers/albums/README.md).

## Проверки

```powershell
python -m unittest discover -s tests -v
cd frontend
npm run build
npx playwright test
```

Браузерные тесты используют установленный Microsoft Edge и отдельный сервер
на порту 8010. SQLite, аккаунты и загруженные картинки тестов размещаются во
временной папке. Реальные данные не изменяются. Скриншоты — `frontend/test-results/`.

Это учебный магазин: платёжная система, реальная доставка и уведомления
не подключены. Для публичной эксплуатации нужны HTTPS, production-сервер,
ограничение попыток входа, восстановление паролей и резервные копии.

Документация стека: https://react.dev/learn/add-react-to-an-existing-project
и https://vite.dev/guide/.
