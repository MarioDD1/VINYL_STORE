# VINYL ROOM — React + Python + SQLite

Магазин виниловых пластинок с гостевым просмотром, кабинетом покупателя и
администратора. React-интерфейс SPIN перенесён из макетов Figma: главная,
каталог, страница альбома и корзина, с адаптацией для телефонов.

Источник: [макеты SPIN](https://www.figma.com/design/7GFEYhv1zCbvBHNzOi0yuz?node-id=1-5).
Общие элементы находятся в `frontend/src/components/Design.jsx`, актуальные
стили — в `frontend/src/styles/spin.css`. Изображения и шрифты подключены
локально из `frontend/public/`. Stinger Fit взят из установленного шрифта,
Inter — из Google Fonts. Исходные SVG сохранены без изменения геометрии.

Товары, цены, остатки и обложки берутся из существующей базы, поэтому содержимое
карточек отличается от примеров в Figma. Фильтры используют доступные поля
каталога. Категории изданий ищут признаки в описаниях товаров; новые поступления —
последние 12 добавленных позиций. Категории без подходящих товаров показывают пустой результат.
Радио воспроизводит шесть предоставленных MP3 из `frontend/public/audio/`
(исходники находятся в `vinyl/`). Плейлист задан в `components/Radio.jsx`.
Поворот пластинки перематывает трек: один оборот равен 30 секундам,
стрелки клавиатуры — 5 секундам. Сервер поддерживает HTTP Range для MP3.
После изменения Python-сервера перезапустите `python run.py`.
На странице альбома показываются реальные характеристики;
рейтинги, несуществующие трек-листы и обещания онлайн-оплаты не подставляются.

В каталог добавлены 36 альбомов с локальными обложками: всего при первом запуске
56 пластинок и 12 жанров. Цены и остатки новых товаров — учебные данные.
Миграция выполняется один раз и сохраняет изменения администратора и удаления.
Источники обложек записаны в `static/covers/albums/sources.json`.
Все жанры выводятся из каталога, сначала отображаются 24 пластинки.

Пластинка в баннере вращается автоматически; её можно повернуть мышью,
касанием или клавишами со стрелками, а автоматическое вращение — поставить
на паузу. Для избранного, корзины, стрелок и кнопок добавлены анимации.
Настройка системы «уменьшение движения» отключает автоматические эффекты.

## Запуск

Нужны Python 3.10+ и Node.js 22.12+ (или 20.19+).
В терминале из папки VINYL_STORE:

```powershell
python -m pip install -r requirements.txt
cd frontend
npm ci
npm run build
cd ..
python run.py
```

Откройте http://localhost:8000. После первой сборки для обычного запуска
достаточно `python run.py`. После изменения React-кода повторите `npm run build`.
При занятом порте остановите прежний сервер через Ctrl+C и запустите новый.

Код регистрации администратора выводится в терминале при запуске.
Перед запуском задайте и сохраните `DB_ENCRYPTION_KEY` — ровно 64 hex-символа
(32 случайных байта). Например, сгенерируйте значение один раз командой
`python -c "import secrets; print(secrets.token_hex(32))"` и сохраните его
в переменных окружения пользователя/сервера. Не генерируйте новый ключ при
каждом запуске и не добавляйте его в Git: потеря ключа сделает БД нечитаемой.

При первом запуске с ключом старая открытая `data/shop.sqlite3` автоматически
переносится в SQLCipher; рядом создаётся зашифрованная резервная копия
`shop.sqlite3.encrypted.bak`. Остановите старый сервер перед миграцией.
Исходный незашифрованный файл не сохраняется. Остальные таблицы и учётные записи
переносятся, существующие аккаунты считаются подтверждёнными. SQLCipher шифрует
также новые данные и файлы журнала SQLite.

Для подтверждения регистрации настройте SMTP переменными окружения:
`SMTP_HOST`, `SMTP_PORT` (587 по умолчанию), `SMTP_FROM`, `SMTP_USERNAME`,
`SMTP_PASSWORD`; для TLS на порту 465 задайте `SMTP_USE_SSL=true`. По умолчанию
используется STARTTLS. Без корректной SMTP-конфигурации новая регистрация
вернёт ошибку отправки, код в ответе или логах не раскрывается. Код действует
15 минут, ограничен пятью попытками и может быть отправлен повторно не чаще
одного раза в минуту.

Покупателю начисляется 5% оплаченной суммы баллами после завершения заказа.
Один балл равен одному рублю; при оформлении можно списать не больше имеющегося
баланса и 30% суммы товаров. При отмене заказа списанные баллы возвращаются.
Можно задать `ADMIN_INVITE_CODE` и `PORT` через переменные окружения.

## Разработка с обновлением без сборки

Терминал 1: `python run.py` (порт 8000).
Терминал 2: `cd frontend`, затем `npm run dev`.
Откройте адрес Vite из терминала (обычно http://127.0.0.1:5173).
Vite проксирует `/api` и `/covers` на Python. Сессии работают через HttpOnly cookie.
Не запускайте `npm run preview` отдельно от API для проверки магазина;
для готовой сборки используйте Python-сервер.

## Структура

```text
frontend/
  src/
    app/                маршруты, общий контекст каталога, аккаунта и корзины
    api/                HTTP-запросы и загрузка файлов
    components/         карточка альбома, обложка, модальное окно
    pages/              главная, каталог, альбом, личный кабинет
    features/
      auth/             вход и регистрация
      cart/             корзина и оформление заказа
      orders/           история и статусы заказов
      admin/            каталог и редактор с загрузкой обложек
    styles/             исходные стили сайта и стили новых страниц
  tests/                браузерный сценарий Playwright
  dist/                 готовая сборка (создаётся npm run build)
shop/                   Python API, SQLite, сессии, права, обработка изображений
static/covers/          запасные SVG и существующие фотографии
static/covers/albums/   фотографии с названиями album-name.jpg
static/covers/uploads/ обложки из админки: ID.jpg (автоматически)
data/shop.sqlite3      база магазина
tests/                 проверки API, обработки файлов и тестовый сервер
run.py                 запуск Python-сервера
```

Серверную папку `shop/` и данные не перемещали, чтобы сохранить прежние пути
и запуск. Старые `static/index.html`, `app.js`, `styles.css` удалены.
В `static/` остаются обложки. Если сборки `frontend/dist` нет, сервер
показывает сообщение «Сначала выполните сборку React» с командами
`cd frontend`, `npm ci`, `npm run build` (HTTP 503). После сборки
достаточно обновить страницу — перезапуск сервера не нужен.
**Для изменения актуального сайта редактируйте `frontend/src/`.**

## Страницы и роли

- `/` — главная с каталогом и блоком о магазине.
- `/catalog` — поиск, жанры и сортировка. Параметры сохраняются в URL.
- `/albums/ID` — отдельная страница альбома, наличие и похожие пластинки.
- `/favorites` — избранное покупателя.
- `/cart` — корзина и оформление заказа.
- `/account` — аккаунт, выход, ссылки на заказы и админку.
- `/orders` — свои заказы; администратор видит все и меняет статусы.
- `/admin` — добавление, редактирование, удаление товаров и обложки.

Гость просматривает каталог. Для корзины и избранного требуется подтверждённый
аккаунт. Регистрация завершается одноразовым кодом из письма; регистрация
администратора также требует код приглашения. Сервер проверяет права, цены,
остатки и списание баллов независимо от React. Отмена заказа возвращает остатки
и списанные баллы один раз; бонусные баллы начисляются при завершении заказа.

## Загрузка обложек

Админка → «Изменить» или «Добавить пластинку» → «Загрузить обложку» →
«Сохранить пластинку». Предпросмотр появится до сохранения.

- JPG, PNG, WebP; максимум 5 МБ и 4096×4096 px.
- Рекомендуется квадрат 1000×1000 px.
- Имя исходного файла может быть любым.
- Сервер декодирует файл, применяет ориентацию EXIF и сохраняет JPEG до 1600 px.
- Файл хранится по ID альбома и не теряется при изменении названия.
- Существующие вручную добавленные изображения продолжают работать.
  Загруженная через админку обложка имеет приоритет.
- Если загрузка не удалась после сохранения товара, повторное сохранение
  обновит этот же товар, не создавая дубль.

Инструкция для ручного копирования:
[имена файлов](static/covers/albums/README.md).

## Проверки

```powershell
python -m unittest discover -s tests -v
cd frontend
npm run build
npx playwright test
```

Браузерные тесты используют установленный Microsoft Edge и отдельный сервер
на порту 8010. SQLite, аккаунты и загруженные картинки тестов размещаются во
временной папке. Реальные данные не изменяются. Скриншоты — `frontend/test-results/`.

Это учебный магазин: платёжная система и реальная доставка не подключены.
Для публичной эксплуатации нужны HTTPS, production-сервер, ограничение попыток
входа и регулярные зашифрованные резервные копии. Храните ключ шифрования отдельно
от БД и резервных копий.

Документация стека: https://react.dev/learn/add-react-to-an-existing-project
и https://vite.dev/guide/.
