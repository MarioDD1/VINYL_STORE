# VINYL ROOM

Учебный интернет-магазин виниловых пластинок. Python 3.10+; установка пакетов не требуется.

## Запуск

```powershell
python run.py
```

Откройте http://localhost:8000. Сервер работает, пока открыт терминал; остановка — Ctrl+C. SQLite создаётся автоматически в `data/shop.sqlite3`, начальный каталог содержит 12 альбомов. Все обложки — локальные авторские SVG-иллюстрации, а не фотографии оригинальных изданий. Google Fonts необязателен: без интернета используются системные шрифты.

Для администратора нажмите «Войти» → «Регистрация», выберите роль и введите код из терминала сервера. Код генерируется при каждом запуске, существующим администраторам он для входа не нужен. Можно заранее задать переменную окружения `ADMIN_INVITE_CODE`; не публикуйте её. Переменная `PORT` меняет порт.

## Возможности

| Роль | Возможности |
| --- | --- |
| Гость | Каталог, поиск по альбому и исполнителю, жанры, сортировка, подробности пластинки |
| Покупатель | Всё выше, избранное, корзина с количеством, оформление заказа, история и статусы своих заказов, выход |
| Администратор | Возможности покупателя, добавление и редактирование пластинок, цена и остатки, удаление из каталога, просмотр всех заказов, изменение статусов |

Регистрация и вход открываются в модальном окне. Права проверяются сервером. Пароли хешируются PBKDF2 с индивидуальной солью, сессии хранятся в SQLite и передаются HttpOnly / SameSite cookie. Заказ рассчитывается по серверным ценам и атомарно уменьшает остатки. Отмена возвращает остатки один раз; отменённый или завершённый заказ закрыт для дальнейших изменений. Удаление пластинки не уничтожает историю заказов. Избранное хранится в аккаунте, корзина — в браузере и очищается при выходе.

Заказы учебные: платёжная система, реальные доставки и отправка уведомлений не подключены. Способ получения — самовывоз, оплата при получении; адрес используется как контактная информация. Для публикации в интернете потребуются HTTPS, production-сервер, ограничение попыток входа, восстановление пароля и резервное копирование. По умолчанию сервер доступен только на локальном компьютере.

## Структура

```text
run.py                     точка входа
shop/database.py           схема SQLite, начальные данные, пароли
shop/server.py             HTTP API, сессии, проверка прав и заказов
static/index.html          главная страница
static/styles.css          адаптивное оформление
static/app.js              каталог, модальные окна, кабинеты
static/covers/             12 локальных SVG-обложек
scripts/generate_covers.py  воспроизводимая генерация обложек
tests/test_shop.py         интеграционные проверки API
data/                      локальные данные, исключены из Git
```

## Проверка

```powershell
python -m unittest discover -s tests -v
node --check static/app.js
```

Тесты используют временную базу и временный локальный сервер, не изменяя каталог и пользователей магазина.

## Настоящие обложки и расширенный каталог

Каталог включает 20 стартовых альбомов. Новые позиции добавляются при запуске
однократной миграцией; существующие записи, цены и заказы не перезаписываются.
Список добавлений: `shop/catalog.py`.

Обложки кладите в **static/covers/albums/**. Рекомендуется JPG 1000×1000 px.
Полный список точных имён и поддерживаемые форматы:
[инструкция по обложкам](static/covers/albums/README.md).

После обновления кода перезапустите сервер. Затем картинки можно добавлять
без перезапуска — достаточно обновить страницу.
