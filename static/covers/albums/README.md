# Настоящие обложки альбомов

Скопируйте изображения прямо в эту папку: `static/covers/albums/`.

- Рекомендуемый формат: **JPG**, квадрат **1000 × 1000 px**, цвет RGB.
- Также поддерживаются `.jpeg`, `.png`, `.webp` с тем же именем до расширения.
- Рекомендуемый вес до 1–2 МБ, размер минимум 600 × 600 px.
- Используйте имена ниже: маленькие латинские буквы, дефисы, без пробелов.
- Не меняйте только расширение: файл должен быть действительно сохранён в этом формате.
- Если есть несколько форматов, порядок выбора: JPG, JPEG, PNG, WebP.
- После копирования обновите страницу (Ctrl+F5). Перезапуск после добавления картинки не нужен.
- Пока файла нет, сайт показывает запасную SVG-обложку.
- Если измените исполнителя или название в админке, имя картинки тоже изменится.
  Подсказка с актуальным именем отображается при редактировании альбома.
